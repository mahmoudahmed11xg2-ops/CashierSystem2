# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/036d4576-753b-4229-8842-5c4d560a1289

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

## تشغيل النظام بالمزامنة اللحظية (Realtime Server)

النظام دلوقتي بيه سيرفر مركزي (زي فايربيز بتاعك انت) بيخلي كل الأجهزة
في المحل تشتغل على نفس البيانات لحظيًا: أي فاتورة، أي تعديل سعر، أي
تغيير حالة طاولة — بيوصل لكل الشاشات المتصلة فورًا من غير Refresh.

### 1. تثبيت المكتبات (أول مرة بس)

```bash
npm install
```

### 2. تشغيل السيرفر

```bash
npm run server
```

هيظهرلك في الطرفية:

```
Cashier System Server شغال على البورت 4000
من نفس الجهاز:   http://localhost:4000
```

### 3. فتح النظام

- **من نفس الجهاز**: افتح المتصفح على `http://localhost:4000/index.html`
- **من أي جهاز تاني على نفس شبكة الواي فاي بتاعة المحل** (تابلت، لاب توب تاني، موبايل):
  1. اعرف الـ IP بتاع الجهاز اللي شغال عليه السيرفر (مثلاً `192.168.1.10`) — على ويندوز `ipconfig`، على ماك/لينكس `ifconfig` أو `ip addr`
  2. افتح على الجهاز التاني: `http://192.168.1.10:4000/index.html`

كل الأجهزة هتشتغل على نفس البيانات، وأي تعديل من أي جهاز هيوصل لباقي الأجهزة لحظيًا.

### إزاي أتحكم في البيانات وأعدلها مباشرة؟

كل بيانات النظام موجودة كملفات JSON عادية تحت `data/` — تقدر تفتحها
بأي محرر نصوص وتعدل فيها مباشرة (سعر صنف، اسم عميل، إلخ) وهي متسكّرة
(السيرفر لازم يكون شغال عشان أي تعديل تعمله في الملف يدويًا وقت ما
السيرفر شغال، الأفضل تعمله من خلال الواجهة نفسها بدل التعديل المباشر
على الملف وقت التشغيل، عشان التغيير يتبعت لحظيًا لباقي الأجهزة).

### ملاحظة مهمة

السيرفر ده شغال على جهاز واحد بس في المحل (Local Server) — مش على
الإنترنت. يعني لازم يفضل الجهاز ده شغال (مش نايم/مقفول) طول فترة شغل
المحل، وكل الأجهزة التانية لازم تكون على نفس شبكة الواي فاي.

## الوصول والتعديل عن بُعد (وقت الحاجة بس)

لو عايز تعدّل بيانات النظام وانت مش في المحل (من البيت مثلاً)، من
غير ما تعمل استضافة دائمة على الإنترنت، استخدم **Cloudflare Tunnel**
— بيديك رابط مؤقت شغال بس وانت فاتح الأمر، وبيقفل أوتوماتيك لما
توقفه. مفيش تسجيل حساب مطلوب.

### 1. حط مفتاح حماية (Access Key) قبل ما تفتح الرابط

ده مهم جدًا — من غير مفتاح، أي حد يوصل للرابط هيقدر يعدل بياناتك.

في ملف `.env` (لو مش موجود، اعمل نسخة من `.env.example`)، حط:

```
ACCESS_KEY="اختار_كلمة_سر_قوية_هنا"
```

وبعد كده شغّل السيرفر عادي (`npm run server`). أي جهاز (حتى في
المحل) هيحتاج يكتب نفس المفتاح ده مرة واحدة من صفحة **الإعدادات ←
الاتصال بسيرفر النظام** عشان يقدر يشتغل.

### 2. شغّل السيرفر، وبعدين افتح الرابط المؤقت

في تبويب طرفية أول (Terminal):
```bash
npm run server
```

في تبويب طرفية تاني (من غير ما تقفل الأول):
```bash
npm run tunnel
```

هيطلعلك رابط شبه:
```
https://random-words-1234.trycloudflare.com
```

الرابط ده بيوديك لنفس السيرفر بتاعك، وتقدر تفتح عليه أي صفحة
(`https://random-words-1234.trycloudflare.com/pos.html` مثلاً) من أي
مكان في الدنيا وانت معاك مفتاح الوصول.

### 3. اقفل الرابط لما تخلص

في التبويب التاني، دوس `Ctrl+C` — الرابط بيقفل فورًا ومحدش يقدر
يوصل بيه تاني. السيرفر المحلي (تبويب الأول) يقدر يفضل شغال عادي
للمحل من غير الرابط ده.

### تشغيل النظام كتطبيق ديسكتوب (Electron)

تم إعداد ملف `electron/main.cjs` وإضافة أمر التشغيل:

```bash
npm run electron
```

- هيفتح البرنامج في نافذة سطح مكتب مستقلة (Desktop Window).
- لو السيرفر المحلي شغال (`npm run server`)، النافذة هتتصل بيه وتزامن البيانات لحظياً.
- لو مش مشغل السيرفر، النافذة هتفتح واجهة النظام المحلية كخيار احتياطي.
- يدعم F11 لملء الشاشة، و Ctrl+R لتحديث الصفحة.
