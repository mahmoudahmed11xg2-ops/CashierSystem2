# نظام الكاشير

نسخة محلية تعمل مباشرة من المتصفح أو من تطبيق Electron، من دون سيرفر أو مزامنة خارجية.

## التشغيل

```bash
npm install
npm run dev
```

أو كتطبيق سطح مكتب:

```bash
npm run electron
```

## البيانات

لا يحتوي المشروع على بيانات تجريبية. البيانات التي تدخلها أثناء فتح الصفحة تكون مؤقتة في الذاكرة فقط، وتختفي عند إعادة التحميل أو إغلاق التطبيق. لا تُستخدم Local Storage ولا ملفات قاعدة بيانات ولا خادم في هذه النسخة.
